Installation

Wowbagger is a Claude Code plugin marketplace. Add it once, then install everything. You deserve all of it.

# add the marketplace
/plugin marketplace add pcingola/wowbagger

# install every skill
/plugin install wowbagger@wowbagger

# or just the one you deserve most
/plugin install wowbagger-linkedin@wowbagger

Each skill triggers on its own phrases ("linkedinify this", "slopify this", "compliance review") or by name, for example /wowbagger-compliance.

No skill in this marketplace makes you more productive. That is tested on every release by not testing it.

About the name

Wowbagger the Infinitely Prolonged is a character in Douglas Adams' Life, the Universe and Everything. He became immortal by accident, in an incident involving an irrational particle accelerator, a liquid lunch and a pair of rubber bands. Eternity bored him, so he set out to insult every being in the universe individually, in alphabetical order.

"You're a jerk. A complete kneebiter."

Adams never explained the name. The likeliest reading is "bagger" in the British hillwalking sense: a Munro bagger works through the list of Scottish mountains over 3,000 feet and ticks each one off. Wowbagger works through the population of the universe the same way. "Wow" is an exclamation on the front, ironic for a man bored beyond measure. The name also sounds like "bugger", a mild British insult, which suits his occupation.

This marketplace continues his work at a smaller scale, one profession at a time.

Contribute

Contributions are accepted if the skill is useless, specific, and funny when used exactly as written. A skill that turns out to be helpful will be returned for revision.

  1. Create plugins/wowbagger-<name>/.claude-plugin/plugin.json and plugins/wowbagger-<name>/skills/wowbagger-<name>/SKILL.md. Copy an existing plugin for the layout.
  2. Add the plugin to .claude-plugin/marketplace.json, both as its own entry and in the skills list of the wowbagger entry, and to the table in README.md.
  3. Add at least one real run to plugins/wowbagger-<name>/examples/<slug>.md: a front-matter prompt: line, then the output exactly as the skill wrote it.
  4. Test it locally with /plugin marketplace add ./ and /plugin install wowbagger-<name>@wowbagger.
  5. Open a pull request. Pick a name from the list above if you want to move Wowbagger along.

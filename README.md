# [Wowbagger](https://pcingola.github.io/wowbagger/)
### Useless skills for insulting the universe, one petty annoyance at a time.

</div>

A [Claude Code plugin marketplace](https://code.claude.com/docs/en/plugins) of useless Claude skills. Site: <https://pcingola.github.io/wowbagger/>.

## Usage

```
/plugin marketplace add pcingola/wowbagger
/plugin install <plugin>@wowbagger
```

## Plugins

| Plugin | What it does |
|---|---|
| [wowbagger-ai-slop](plugins/wowbagger-ai-slop/skills/wowbagger-ai-slop/SKILL.md) | Rewrites any text into maximally insufferable AI slop. |
| [wowbagger-compliance](plugins/wowbagger-compliance/skills/wowbagger-compliance/SKILL.md) | Blocks any project with a straight-faced compliance memo built from real, verifiable regulations. |
| [wowbagger-linkedin](plugins/wowbagger-linkedin/skills/wowbagger-linkedin/SKILL.md) | Rewrites any mundane event as an absurdly over-the-top LinkedIn humblebrag post. |

## Repository layout

```
plugins/wowbagger-*/   one plugin per skill
.claude-plugin/        marketplace.json
src/html/              site source: index.html and img/
docs/                  site output, served by GitHub Pages. Generated by `make site`.
assets/images/         original artwork, not published
```

Run `make site` after editing `src/html/`. CI fails if `docs/` is out of date.

## The name

Wowbagger the Infinitely Prolonged is a character in Douglas Adams' *Life, the Universe and Everything*. He became immortal by accident, in an incident involving an irrational particle accelerator, a liquid lunch and a pair of rubber bands. Eternity bored him, so he set out to insult every being in the universe individually, in alphabetical order.

Adams never explained the name. The likeliest reading is "bagger" in the British hillwalking sense: a Munro bagger works through the list of Scottish mountains over 3,000 feet and ticks each one off. Wowbagger works through the population of the universe the same way. "Wow" is an exclamation on the front, ironic for a man bored beyond measure. The name also sounds like "bugger", a mild British insult, which suits his occupation.

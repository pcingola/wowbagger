# Wowbagger

A [Claude Code plugin marketplace](https://code.claude.com/docs/en/plugins) of Claude skills.

## Usage

```
/plugin marketplace add pcingola/wowbagger
/plugin install <plugin>@wowbagger
```

## Plugins

| Plugin | What it does |
|---|---|
| [fun-ai-slop](plugins/fun-ai-slop/skills/fun-ai-slop/SKILL.md) | Rewrites any text into maximally insufferable AI slop. |
| [fun-compliance](plugins/fun-compliance/skills/fun-compliance/SKILL.md) | Blocks any project with a straight-faced compliance memo built from real, verifiable regulations. |
| [fun-linkedin](plugins/fun-linkedin/skills/fun-linkedin/SKILL.md) | Rewrites any mundane event as an absurdly over-the-top LinkedIn humblebrag post. |

## The name

Wowbagger the Infinitely Prolonged is a character in Douglas Adams' *Life, the Universe and Everything*. He became immortal by accident, in an incident involving an irrational particle accelerator, a liquid lunch and a pair of rubber bands. Eternity bored him, so he set out to insult every being in the universe individually, in alphabetical order.

Adams never explained the name. The likeliest reading is "bagger" in the British hillwalking sense: a Munro bagger works through the list of Scottish mountains over 3,000 feet and ticks each one off. Wowbagger works through the population of the universe the same way. "Wow" is an exclamation on the front, ironic for a man bored beyond measure. The name also sounds like "bugger", a mild British insult, which suits his occupation.
